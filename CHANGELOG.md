# Changelog

All notable changes to the 1Shot Labs Plugin Marketplace will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.1.0] - 2025-01-18

### Updated

- Squadron Comms plugin updated to v1.1.0
  - Major redesign to use ElevenLabs MCP play_audio tool
  - Simplified dependencies (PortAudio instead of mpv)
  - Improved cross-platform compatibility
  - Enhanced Windows support

## [1.0.0] - 2025-01-18

### Added

- Initial marketplace release
- Squadron Comms plugin v1.0.0
  - Voice communication system with ElevenLabs TTS
  - Four specialized squadron agents (Red, Gold, Blue, Green)
  - Mission logging and coordination features
